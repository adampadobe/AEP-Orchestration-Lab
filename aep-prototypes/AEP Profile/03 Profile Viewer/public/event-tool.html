⚙ Configuration Saved

Two steps: provision schema + dataset in AEP, then wire a Data Collection datastream. After Step 1, enable the schema and dataset for Profile with alternate primary identity (identityMap per event).

Step 1 — Set up event infrastructure

One click creates the ExperienceEvent schema (Experience Event Core v2.1, Interaction Details Lite, Travel - Hotel Experience v1, B2C Event Identity v1, Booker/Stayer), registers ECID and Email as secondary identity descriptors on _{tenant}.identification.core.*, and creates the linked dataset. Safe to re-run — existing assets are skipped.

    Step 2 — Datastream in Data Collection

    In AEP Data Collection → Datastreams, create a datastream for the schema and dataset from Step 1. Enable Adobe Experience Platform and select your dataset. Copy the datastream ID, paste it below, then click Save configuration. For Tags, add the Web SDK extension and set Edge Config to this ID (Tags).
