    Observed website engagement

    Sessions group observed website events per account with a 30-minute inactivity cutoff. Active time is a conservative estimate from focused, visible pages with recent interaction; overlapping tab reports are merged. Reading without interaction, shutdown and lost requests can undercount. This is not exact time spent.

    Read caps and the selected window can split sessions or omit activity. No heartbeat history means active time is not recorded, not zero. Owner exclusion also removes identifiable owner records and key inventory from the other sections; unattributed history cannot be excluded reliably.

    MCP dispatch outcomes

    Separate from operational audits: one record when an authenticated tools/call dispatch finishes. Collection defaults off and live configuration is not inspected here. Retained history remains readable when collection stops.

    An SDK result without isError is not proof of business success or background-job completion. SDK input-validation failures and disabled/unknown tools are rejected before handler execution. Crashes, persistence failures, rejected authentication, malformed protocol requests and lost responses leave gaps; these counts are partial.
