Reference for Adobe-hosted MCP servers with documented HTTPS endpoints: what each server does, its URL, how it is usually enabled in Cursor, and where to read official setup guides. Local stdio-only MCPs are not listed here. This page does not store credentials and is not Adobe-sandbox-dependent.

About MCP in Cursor

Model Context Protocol (MCP) lets Cursor (and other agents) call external tools with structured schemas instead of guessing APIs. This catalog is intentionally sandbox-independent UI: it remains available with no Adobe sandbox selected and can be used to plan non-AEP workflows too.

Entries in this catalog use streamable HTTP (https://…/mcp) and OAuth (Adobe ID) unless noted otherwise in official docs. Test mutating workflows in non-production sandboxes first; validate tool output before acting on it.
