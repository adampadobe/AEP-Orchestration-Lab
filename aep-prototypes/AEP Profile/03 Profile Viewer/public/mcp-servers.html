Entry point

aep-lab-entry

Connect this small directory alongside your other connections. It explains the other Lab domains, recommends the smallest one for a prompt, and can load a domain toolset — profile, audiences, ajo-cleanup, decisioning, demo-prep, pdf, command-centre, or weather — into the same session with lab_load_toolset, on clients that honor the MCP tool-list-changed refresh.

Known limitation in Adobe Coworker: as tested, Coworker's tool discovery only reflects the tools present when a session starts and does not re-check the list after lab_load_toolset runs, so newly loaded tools register but never become callable there. In Coworker, also directly connect the focused endpoint(s) below for the domains you actually use — for example aep-lab-profiles for profile and event work, or aep-lab-demo-prep for brand scraping and customer prep.

Your API key

One personal key per Adobe sandbox. Keys follow your global sandbox in the nav — switch sandbox to manage another. Authenticate with header X-AEP-Lab-Mcp-Key.

Main workflows

  • Profiles — generate golden test profiles, batch seed, lookup and update UPS
  • Brand scrape → demo prep — crawl a site, map personas to profiles, optional events and Client Journey asset
  • Events — send any experience event type (same as Event tool), verify on profile activity
  • PDF preparation — preview HTML or document data, generate and store PDFs, then retrieve private preview links
  • Sandbox config — infra readiness, onboard industries, verify MCP access
  • HTTP streaming flows — lab MCP creates schema + dataset; use Coworker dx-api (Flow Service) for profile dataflows, then save connection in Profile Viewer
  • Edge datastreams — lab_setup_event_infra + lab_enable_event_profile; Coworker dx-api for the datastream; lab_save_event_datastream to wire Event tool sends

Getting started

  1. Select your sandbox in the Profile Viewer nav
  2. Sign in and Generate key below — workspace slug is not required first
  3. Add to Coworker or Cursor: endpoint in the table, header X-AEP-Lab-Mcp-Key — or use Copy Coworker config
  4. First Coworker session: call lab_mcp_first_run_setup for your sandbox (pass workspace_slug when prompted)
  5. Then lab_get_execution_framework before other lab tasks
  6. Missing HTTP dataflow after schema/dataset provision? Coworker dx-api — see HTTP streaming flows doc
  7. Event tool needs a datastream? lab_setup_event_infra then dx-api — see Edge datastreams doc

Tool reference: README. Brand scrape with wait needs MCP client timeout ≥ 540s; most other tools ≥ 300s.
