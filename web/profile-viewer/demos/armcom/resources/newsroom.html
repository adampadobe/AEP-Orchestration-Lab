Arm unveils AGI CPU — production silicon for agentic AI data centers

Cambridge, UK — Arm today announced the Arm AGI CPU, its first production silicon purpose-built for rack-scale agentic AI orchestration in converged data centers.

The AGI CPU coordinates accelerators, manages memory hierarchy, and sustains thousands of concurrent agents while delivering industry-leading performance per watt. Early hyperscaler partners report more than 2× rack-level efficiency versus legacy x86 head-node designs.

“Agentic AI changes how data centers operate — the CPU must orchestrate, not just compute,” said Rene Haas, CEO of Arm. “The AGI CPU is the foundation for that next era.”

Arm is publishing a technical brief for infrastructure architects evaluating cloud AI roadmaps. The brief includes benchmark methodology, TCO models, and migration guidance for Neoverse-based platforms.
